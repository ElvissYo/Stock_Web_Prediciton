# IHSG Forecasting Dashboard

Public dashboard for Indonesian stock market monitoring, prediction, and news sentiment.

The app serves:

- market overview and movers
- ticker-level prediction
- recent news and NLP summary
- technical price features
- model metrics

It runs as a Docker Space on the free CPU Basic hardware.
